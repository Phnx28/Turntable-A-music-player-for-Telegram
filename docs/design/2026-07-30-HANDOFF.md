## 5. The plan's decided shape — 23 tasks, 4 phases

This is already worked out. Write it up; don't redesign it.

### Phase 1 — correctness, no visual change, independently shippable (tasks 1–10)

1. **A2 queue contradiction.** New pure `queueView(queue, queueIndex)` in
   `static/player-core.js` → `{total, upcoming, isEmpty, summary}`. Summary
   strings: `"Your queue is empty"` / `` `${total} in queue · last track` `` /
   `` `${total} in queue · ${upcoming} up next` ``. The bug is at
   `app.js:1089` (counts only `upcoming`) and `app.js:1099` (concatenates the
   empty state *after* rows). Test in `static/player-core.test.js`.
2. **A3 dead header collapse.** New pure `shouldCompactHeader({scrollTop,
   scrollHeight, clientHeight, headerHeight, compact})`. **The audit's
   suggested fix ("drop `- header.offsetHeight`") is wrong** — the header is a
   sibling of `#now-content`, so collapsing it grows `clientHeight` and the
   oscillation the existing comment at `app.js:1366-1378` describes is real.
   Correct fix subtracts only the *freed* height:
   `freed = max(0, headerHeight - COMPACT_HEADER_HEIGHT)` with
   `COMPACT_HEADER_HEIGHT = 72` pinned in CSS so the constant is exact.
   Regression case for the test: scrollHeight 1000, clientHeight 500,
   headerHeight 520 → old arithmetic gives −20 (false), new gives 52 (true).
   The "header eats 67% of the panel" complaint is a *separate* fix: cap the
   expanded header at ≤45% of panel height (spec §4.3).
3. **Rail row restructure** — folds A4 + A5 + D1 + D11 + E3. Count becomes a
   real grid column (today it is inside `opacity: 0` `.source-actions`, and
   `style.css:977` additionally sets `.source-link:hover .source-count
   { display: none }`, so it is visible in *no* state). Add
   `sourceKindLabel()` in a **new `static/format.js`**. Collapse the three
   icon buttons into one always-rendered `⋯` reusing
   `openMenu(actions, x, y)` (`app.js:1411`, dispatch at `app.js:2091`,
   actions shaped `[{label, action, danger}]`). Bulk verb becomes
   **"Remove from library"** — it currently says "Unselect" but POSTs
   `/api/sources/bulk-select` false, which *removes sources*.
4. **A6** collapsed rail: `width: 100%; max-width: 46px`
   (`style.css:1001` sets `width: 46px`, giving clientWidth 45 / scrollWidth
   46 → a horizontal scrollbar with arrows).
5. **A7** `.metadata-form .inline-choice` scoping (`.metadata-form label`
   at (0,1,1) beats `.inline-choice` at (0,1,0), so the three metadata
   buttons render 62px instead of 40px) + `.form-actions { align-items: center }`.
6. **A8** on `fetchMetadata` catch (`app.js:1275-1285`), clear
   `#candidate-list` and hide `#candidate-section`; today it only writes
   `#metadata-status`.
7. **`tests/test_layout.py`** Playwright harness: `unittest` + `skipIf` on
   import failure, `ThreadingHTTPServer` with
   `partial(SimpleHTTPRequestHandler, directory="static")` on port 0,
   `page.route("**/api/**")` stubs ported from `seed.js`. First assertion is
   **A1**: mobile Now Playing gets `bottom: var(--player-height)` instead of
   `inset: 0`, in **both** 860px blocks (`style.css` ~872-886 and 1222).
   Today `#now-panel` is `fixed; inset: 0; z-index: 25` over `#player` at
   `z-index: 10`, and `elementFromPoint` at the play button returns
   `SECTION#now-panel`.
8. **A9** restore `.search-control` and the track count on mobile
   (`style.css:871` hides both; `style.css:1243` also hides
   `.source-link .source-count` under `(hover: none), (pointer: coarse)`).
9. **A10** zero-result states: drop the `TRACK / SOURCE / TIME` head and
   disable Play/Shuffle when there are no rows.
10. **B8** error dialog (`showError`, `app.js:81-87`): show `error.message`
    only for authored `AppError`s (`app.js:28-32`, thrown in `api()` at
    `app.js:34-51`); otherwise a written fallback plus Retry when retryable.
    Today raw exception text reaches users ("The element has no supported
    sources.").
